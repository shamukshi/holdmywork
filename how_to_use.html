How to use

Build automation using simple icons.

Each icon represents an action. Arrange them in order, connect them, and your workflow is ready.

Your icon guide

🌐

Open a website or launch Chrome.

☝

Mouse

Perform a mouse click at a specified location.

▦

Keyboard

Press a keyboard key or keyboard shortcut.

✍️

Typing

Type text automatically.

▣

App

Open an application using its file path.

→

Arrow

Connect actions and define the sequence of the automation.
